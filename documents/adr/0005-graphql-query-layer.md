# ADR-0005: Read-only GraphQL query layer over the domain tables

- Status: **Superseded** by [ADR-0010](0010-matchingprofile-dataloader-batching.md)
- Date: 2026-11-20
- Plan: documents/plans/2026-11-20-colombus-persistence-migration.md

## Context

The persistence service must expose the domain schema to colombus. The plan
called for a Strawberry GraphQL read surface over the eight tables, with types
generated by `strawberry-sqlalchemy-mapper==0.9.0` and a manual type for the
composite-PK `MatchingProfile`.

## Decision

- `app/graphql.py` builds a `StrawberrySQLAlchemyMapper` with
  `always_use_list=True` (relationships resolve as plain lists, not Relay
  connections) and auto-maps `Project`, `Profile`, `Step`, `CellOutput`,
  `MetaInstruction`, `Code` and `Pattern`. `MatchingProfile` is exposed as a
  hand-rolled `MatchingProfileType` (`pattern_hash`, `profile_id`, and a
  `profile` resolver) because its composite primary key has no scalar `id`.
- The mapper is taught two extra type mappings: SQLModel columns are typed as
  generic `sqlalchemy.Uuid` and `AutoString`, which are distinct classes from
  the mapper's Postgres `UUID`/`String` defaults — they map to `uuid.UUID` and
  `str` respectively.
- A `Query` root type exposes `projects`, `project(id)`, `profiles`,
  `profile(id)`, `patterns` and `matching_profiles`, plus a DB-free
  `onePlusOne` used by the endpoint contract tests.
- `build_schema_context(session)` assembles a request context carrying the
  session and a `StrawberrySQLAlchemyLoader(bind=session)` for relationship
  batching. `get_graphql_context()` is a generator that opens a session from
  the application engine, yields the context, and closes it when the request
  completes. `app/main.py` wires it as the router's `context_getter`.
- Because the mapper constructs Strawberry classes at runtime, pyrefly cannot
  statically prove `list[Model] -> list[StrawberryType]`; the handful of
  resolver return statements carry a targeted `# type: ignore[bad-return]` so
  the 100% typing gate on `app/` is preserved.

## Consequences

- Colombus can query projects, profiles with their full nested step/meta/code
  graph, patterns and match results over HTTP.
- One session per request, released on completion — no leaked sessions in the
  router path.
- Mutations and any write path are deliberately deferred to ADR-0006.
